NEV369

Post-quantum Layer-1

Network

NEV369 is an open network: anyone can run a node and mine. This is the live view from the public node at q-lock-ecosystem.com — every block anyone mines reaches it.

Mine NEV369 — two commands

Every block pays 369 NEV to whoever mines it. Mining runs a full node on your own computer: it downloads the chain, checks every block, and searches for the next one. Open a terminal and paste:

curl -fsSL https://q-lock-ecosystem.com/downloads/install.sh | bash
nev369-mine

The first run creates your wallet — choose a password, at least 10 characters. There is no recovery: back up ~/.nev369/wallet.json and remember the password. Leave the terminal open while it mines; Ctrl+C stops it and it resumes where it left off.

Linux, Chromebook and Mac: the two commands above, in a terminal. Windows: download nev369-windows-x86_64.zip, unzip it and double-click START-MINING.cmd. The files aren't code-signed yet, so Windows may warn: More info → Run anyway, then allow network access when the firewall asks.

Bridge

NEV369 ⇄ Ethereum

How authorization works

The coordinator holds no signing key. Independent signers each observe NEV369 and submit a signed attestation; a mint is authorized only when a threshold of them agree on byte-identical terms, past finality, inside the exposure limits, with the circuit closed.

Authorizationm-of-n threshold
Coordinator keynone held
Replayone mint per lock id
Finalityconfirmations required
Exposureper-mint · per-window · total
Circuit breakertrips on reconciliation gap

Units

NEV369 and wNEV both use 8 decimals, so bridging is 1:1 in base units with no scaling. A 1010 factor anywhere means something removed has come back.

GodShield

Post-quantum security · Dilithium5 · NIST Level 5

Quantum-risk scanner

Paste source code. GodShield flags the cryptography a quantum computer breaks — RSA, ECDSA, secp256k1, Ed25519, Diffie-Hellman and friends — and writes a migration plan to post-quantum signatures.

Verify a signature

Check a Dilithium5 signature against a public key. Nothing secret is ever sent — verification needs only public data.

Gateway audit trail

Every gateway decision is appended to a hash-linked log. Each entry commits to the one before it, so any edit to history breaks the chain — and anyone can check it.

Keys stay on your machine

GodShield never generates or holds your secret keys on a server — a key made on someone else's computer isn't really yours. Make them locally with the GodShield command-line tool:

godshield wallet new # NEV369 wallet, password-sealed godshield keygen --output key.json # raw Dilithium5 keypair godshield vault create ... # split a key across guardians

Public keys are ~2.6 KB and signatures ~4.6 KB — that size is the real engineering cost of moving to post-quantum cryptography.
